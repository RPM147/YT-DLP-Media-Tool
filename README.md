# 🎥 RPM's Media Tool v2.0

![Python](https://img.shields.io/badge/Python-3.10+-blue?style=for-the-badge&logo=python)
![PyQt6](https://img.shields.io/badge/PyQt6-v6.4+-green?style=for-the-badge&logo=qt)
![yt-dlp](https://img.shields.io/badge/Powered%20By-yt--dlp-red?style=for-the-badge)

**RPM's Media Tool**, YouTube, Instagram, TikTok, Twitter (X) ve daha yüzlerce platformdan yüksek kalitede video ve ses indirmenize olanak tanıyan, modern arayüzlü ve güçlü bir masaüstü uygulamasıdır. `yt-dlp` motoru üzerine inşa edilmiş olup, kullanıcı dostu bir deneyim sunar.

---

## ✨ Özellikler

- 🚀 **Geniş Platform Desteği:** YouTube, Instagram, TikTok, Twitch, Facebook, X ve daha fazlası.
- 📺 **Yüksek Kalite Seçenekleri:** 4K (2160p), 2K (1440p), 1080p, 720p ve diğer çözünürlükler.
- 🎵 **Ses Dönüştürme:** Videoları doğrudan MP3, AAC, FLAC, WAV gibi formatlarda indirme.
- ⏳ **Gelişmiş Kuyruk Yönetimi:** Birden fazla videoyu sıraya ekleyip sırayla indirme.
- 📋 **İndirme Geçmişi:** Tamamlanan indirmelerin kaydını tutma ve hızlı erişim.
- 🍪 **Çerez Desteği:** Tarayıcıdan veya dosyadan çerez (cookie) içe aktararak gizli veya yaş kısıtlamalı videoları indirme.
- 🎨 **Modern Arayüz:** Catppuccin Mocha esintili karanlık tema ve canlı hız grafiği.
- 🛠 **Ekstra Seçenekler:**
  - Altyazıları gömme (EN & TR).
  - Küçük resim (thumbnail) ekleme.
  - Video açıklamalarını kaydetme.
  - Eşzamanlı parça indirme ile maksimum hız.

---

## 🛠 Kurulum ve Çalıştırma

### Gereksinimler
- Python 3.10 veya üzeri
- FFmpeg (Video birleştirme ve ses dönüştürme için gereklidir)

### Adımlar
1. Depoyu klonlayın:
   ```bash
   git clone https://github.com/Furkan-FS/YT-DLP-Media-Tool.git
   cd yt-dlp-media-tool
   ```

2. Gerekli kütüphaneleri yükleyin:
   ```bash
   pip install PyQt6 yt-dlp requests
   ```

3. Uygulamayı başlatın:
   ```bash
   python main.py
   ```
